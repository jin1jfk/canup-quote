# Canup 見積書発行

株式会社Canup の見積書をブラウザで作り、その場でPDFを発行するアプリ。

- 画面: `index.html`(GitHub Pages で公開)
- 記録先: Googleスプレッドシート「株式会社Canup_物件管理リスト」にバインドした Apps Script(`gas/`)
  - 見積番号の採番と「見積台帳」への記録、PDFのDrive保存を行う
  - 画面からは合言葉付きのPOSTで呼ぶ。合言葉は「設定」シートにだけあり、このリポジトリには置かない

## 初回の設定
1. スプレッドシートの「見積書」メニューから「初期設定」を実行(Googleの承認が要る)
2. Apps Script をウェブアプリとしてデプロイ(実行ユーザー: 自分 / アクセス: 全員)し、`/exec` のURLを控える
3. この画面の「接続設定」に、そのURLと「設定」シートの合言葉を入れる

お客様の情報・金額はこのリポジトリに保存しない。
