# Canup 見積書発行

株式会社Canup の見積書をブラウザで作り、その場でPDFを発行するアプリ。

- 画面: `index.html`(GitHub Pages で公開)
- 記録先: Googleスプレッドシート「株式会社Canup_物件管理リスト」にバインドした Apps Script(`gas/`)
  - 見積番号の採番と「見積台帳」への記録、PDFのDrive保存を行う
  - 画面からは合言葉付きのPOSTで呼ぶ。合言葉は「設定」シートにだけあり、このリポジトリには置かない

## 初回の設定
1. スプレッドシートの「見積書」メニューから「初期設定」を実行(Googleの承認が要る)
2. Apps Script をウェブアプリとしてデプロイ(実行ユーザー: 自分 / アクセス: 全員)し、`/exec` のURLを控える
3. この画面の「接続設定」に、そのURLと「設定」シートの合言葉を入れる

お客様の情報・金額はこのリポジトリに保存しない。

## 案件管理(anken.html)
- 画面: https://jin1jfk.github.io/canup-quote/anken.html (スマホ可)。接続先は見積書と同じ Apps Script
- 原本=このスプレッドシートの「物件管理」。アプリで読み書きし、保存のたびに「公開する列」だけを
  別ファイル「株式会社Canup_物件管理リスト(閲覧用)」に書き写す。社内に共有するのは閲覧用だけ
  (原本を閲覧共有すると「設定」シートの合言葉・振込先まで見えるため)
- 合言葉は2種類: 「アプリの合言葉」=管理者(見積・請求+案件の全列) / 「案件_担当の合言葉」=担当者(案件の公開列だけ)
- 列を隠す: 設定シート「公開する列」から列名を消す → 閲覧用と担当者の画面から消える(原本と管理者画面には残る)
- 列の型(日付・選択肢・チェック・金額・自動)は物件管理の入力規則・数式・表示形式から自動で判定する。列を足しても画面が追従する
- 支払アラートは日付で変わるので、日付が変わって最初に一覧を開いたときにも閲覧用へ反映し直す。手動はメニュー「見積書 > 閲覧用ファイルに反映」
